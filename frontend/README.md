# Two of Us: frontend

Next.js 16 (App Router, TypeScript strict, Tailwind 4). In Phase 1 this is a
placeholder status page plus the same-origin proxy: every `/api/*` request is
rewritten to the FastAPI backend (`next.config.ts`, `BACKEND_INTERNAL_URL`).
The real interface and the installable PWA are built in Phase 2.

```bash
source ../scripts/env.sh   # use the project-local Node in WSL if needed
npm ci
npm run dev                # http://127.0.0.1:3000 (always 127.0.0.1, not localhost)
npm run lint && npm run typecheck && npm run build
```

`AGENTS.md` was generated by `create-next-app`. It reminds coding agents to read
the version-matched docs in `node_modules/next/dist/docs/` before writing
Next.js code. See `../docs/` for architecture, setup and security notes.
